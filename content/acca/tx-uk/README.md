# ACCA TX-UK

This directory contains the original Quarto study material for the ACCA Taxation (TX-UK) exam.

- `source/` contains the original `.qmd` notes and supporting assets.
- `rendered/` is generated by Quarto during deployment and is not committed.
- `rendered-archive/` contains older HTML exports retained for reference.

The student-friendly graph articles are maintained separately in [`../../../wiki/`](../../../wiki/).
