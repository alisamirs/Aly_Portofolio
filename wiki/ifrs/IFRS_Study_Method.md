# IFRS Study Method

Use the graph as an index across the local IFRS, IAS, IFRIC, and SIC source collections. Begin with the Conceptual Framework, then study each Standard by objective, scope, recognition, measurement, presentation, disclosure, and judgement areas.

The graph records source-document traceability without republishing the source PDFs. Requirements can change, so the current authoritative IFRS Foundation material should always be checked.
