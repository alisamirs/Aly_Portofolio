# IFRS Study Method

This collection is organised as a connected study map rather than a replacement for the authoritative standards.

## Suggested route

Start with the purpose and recognition model of each standard, then map measurement, presentation, disclosure, and common judgement areas. Use the original source PDFs in the IFRS Study folder for detailed requirements and exam preparation.
